Privacy Policy

Hermes FieldPro — last updated 28 October 2026

1. Who this applies to

Hermes FieldPro is a private automation used by a single individual ("the owner") on the owner's own computer. It accesses only the owner's own Google account, with the owner's explicit consent given through Google's standard OAuth 2.0 consent screen. No other person's data is accessed.

2. What is accessed

With the scopes granted at authorisation, the application can:

  • search and read messages in the owner's Gmail mailbox;
  • download attachments from those messages;
  • apply or remove Gmail labels on those messages (for example, to mark a report as already collected).

In practice the application reads only messages matching a narrow search for scheduled report emails from a field-operations reporting service, plus their attachments. Google OAuth access tokens and refresh tokens are stored as a single credential file on the owner's computer.

3. How data is used

Downloaded report attachments are saved to a folder on the owner's computer and used solely for the owner's own business analysis. The application does not build advertising profiles, does not sell data, and does not make automated decisions about any individual.

4. What is shared

Nothing is shared with third parties. There is no analytics service, no external database, and no remote server operated by this application. Data leaves the owner's computer only if the owner personally copies or sends a report elsewhere.

5. Where data is stored, and for how long

Report files and the OAuth credential file are stored locally on the owner's computer, and report files may be synchronised to the owner's own cloud storage account at the owner's discretion. Report files are retained as long as the owner needs them for analysis and can be deleted by the owner at any time. No copy is retained by the application's author.

6. Email content

Message bodies are read only to locate report attachments and to identify the report period. The application does not send email on the owner's behalf, and does not forward, publish, or upload message content anywhere.

7. Revoking access

The owner can revoke this application's access at any time at myaccount.google.com/permissions. Revoking access immediately stops all further reading of the mailbox. Deleting the local credential file has the same effect on the application side.

8. Security

The credential file is stored on the owner's computer and is not transmitted to the application's author. Google's OAuth refresh tokens are the only long-lived secret; access can be withdrawn unilaterally by the owner at any time (see section 7).

9. Children

This application is not directed at children and processes no data about children.

10. Changes

If this policy changes, the updated version will be published at this address with a new "last updated" date.
