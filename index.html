Hermes FieldPro

A private, single-user automation for downloading scheduled report attachments.

What this application is

Hermes FieldPro is a personal tool run by one individual on their own computer. It connects to the owner's own Gmail account through Google's OAuth 2.0 authorisation, searches that mailbox for scheduled report emails from a field-operations reporting service, saves the attached report files to a folder on the owner's computer, and files them for the owner's own analysis.

It is not a public service. There is no sign-up, no account for anyone else, and no server that receives data from third parties. The only permitted user is the owner of the mailbox it reads.
